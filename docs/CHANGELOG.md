# Changelog / تاریخچه تغییرات

See the root [CHANGELOG.md](../CHANGELOG.md) for the complete release history of **Chande (چنده)**.

برای مشاهده فهرست کامل تغییرات نسخه‌های **چنده (Chande)** به فایل اصلی [CHANGELOG.md](../CHANGELOG.md) مراجعه کنید.

- **v1.2.0 (2026-11-03):** Integrated GitHub Releases Automatic Update System (SemVer comparison, SHA-256 verification, staging & rollback, user-data preservation), Settings > About & Updates tab, GitHub Actions release pipeline, exact desktop position persistence, and complete bilingual documentation.
- **v1.1.0 (2026-10-30):** Intelligent Win32 desktop occlusion sleep & instant wake, full Persian (RTL) & English (LTR) runtime localization, and smooth Win32 edge/corner resizing across Expanded, Compact, and Ultra-Compact modes.
- **v1.0.0 (2026-10-25):** Initial release with Windows 7 desktop gadget behavior, Navasan API integration (`usd_sell`, `18ayar`, `btc`, `usdt`), strict 120 requests/month quota manager, and offline-first local cache.
